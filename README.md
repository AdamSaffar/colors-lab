# COLORS

COLORS is a simple web application built using the LAMP stack. The application allows users to log in, add colors to their account, and search for previously added colors.

Created for the COP4331C COLORS Web Application Labs 1–3, this project features a JavaScript frontend that communicates with PHP API endpoints connected to a MySQL database.

## Technologies Used

- Linux
- Apache
- MySQL
- PHP
- HTML
- CSS
- JavaScript

# Features
- User login
- Add colors
- Search saved colors
- User session information stored using browser cookies

# Setup
1. Setup a LAMP environment with Linux, Apache, MySQL, and PHP.
2. Clone this repository into the Apache web directory.
3. Create a MySQL database for the application.
4. Setup the required Users and Colors tables.
6. Start Apache and MySQL.

# Running the Application
After the project has been placed in the Apache web directory and the database has been setup, open the application through the web server in a browser.

The exact URL will depend on your configuration.

The application starts at index.html. After login, the user is redirected to color.html.
